# gt6_modpacks
以GT6M 主导的 26.1.2 NeoForge 整合包
以 GregTech 6 的材料与机器体系为主轴，把科技、农业、魔法、存储、探索类模组的配方统一"GT6 化"
使用nekojs魔改

配方魔改体系
保留模组原有配方结构，把其中的材料替换成 GT6 对应物。

1. GT6 材料字典
封装了 36 种材料（铁/铜/锡/铅/金/银/镍/锌/铝/青铜/黄铜/钢/不锈钢/镀锌钢/钛/钨/钨钢/铌钛合金/铂/铀/红合金/硅/钻石/绿宝石/煤/青金石/黑曜石/红石/萤石/末影珍珠/橡胶/塑料/下界石英/赛特斯石英/充能赛特斯/福鲁伊克斯）；
封装了 20 种物品形态（板/弯曲板/双层板/致密板/宝石板/宝石薄板/螺丝/螺栓/环/杆/长杆/箔/齿轮/小齿轮/粉/小堆粉/锭/宝石/小机壳/细线）+ 4 种机壳方块形态；
GT6 本体实际支持的形态有 106 种，需要时可按同一套接口追加（例如转子、弹簧、碎矿、宝石碎粒、工具头等）。

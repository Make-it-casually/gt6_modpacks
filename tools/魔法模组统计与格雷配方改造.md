# 魔法模组统计与格雷配方改造

统计范围为当前 `mods/` 目录内已启用的魔法内容模组、其玩法扩展以及直接补丁/整合组件；同一模组的依赖库不计入。

## 模组统计

当前共 **21 个**相关模组：

| 分类 | 数量 | 模组 |
|---|---:|---|
| 核心体系 | 4 | Thaumcraft（神秘时代）、Botania（植物魔法）、Blood Magic（血魔法）、Witchery（巫术） |
| 内容扩展 | 13 | Alfheim、Blood Arsenal、Deathly Hallows、Forbidden Magic、Forgotten Relics、Magic Bees、Tainted Magic、Thaumic Bases、Thaumic Concilium、Thaumic Horizons、Thaumic Tinkerer、Thaumic Additions、WarpTheory |
| 跨模组整合 | 1 | Thaumic Energistics（Thaumcraft + Applied Energistics 2） |
| 补丁/接口 | 3 | Thaumcraft4Tweaks、Thaumic Duality Interface、WitcheryPatch |

### 独立进度与依赖关系

- 四个核心体系各有自己的入口与进度链。
- Alfheim、Blood Arsenal、Forbidden Magic、Forgotten Relics、Tainted Magic、Thaumic Bases、Thaumic Concilium、Thaumic Horizons、Thaumic Tinkerer、Thaumic Additions、WarpTheory 均扩展现有魔法体系；其中多个关键配方依赖 Thaumcraft 研究、注魔或 Botania / Blood Magic 的既有机制，不是普通工作台入口。
- Magic Bees 的主要进度是蜂种繁育与蜂产品链；Thaumic Energistics 的主要进度是 AE2/精华整合配方。这两者没有可安全替换的通用魔法起始工作台配方。
- Deathly Hallows 提供独立主题物品，但当前安装 JAR 没有可用于核对配方入口的 `mcmod.info`；本轮不对未确认的物品 ID 或配方做猜测性替换。
- Thaumcraft4Tweaks、Thaumic Duality Interface 与 WitcheryPatch 是调整/接口组件，不作为独立进度线处理。

## 已改配方

配方分散在现有的模组脚本中：[`scripts/38_thaumcraft.zs`](../scripts/38_thaumcraft.zs)、[`scripts/32_botania.zs`](../scripts/32_botania.zs)、[`scripts/45_bloodmagic.zs`](../scripts/45_bloodmagic.zs)、[`scripts/46_witchery.zs`](../scripts/46_witchery.zs)。四个核心起始工作台配方现在均要求 `<ore:blockPlateSteel>`。当前实例的 `logs/oredict.log` 能确认 GT6 注册了 `blockPlateSteel`，但没有确认 `plateSteel` 矿词；因此使用已验证的钢板块词条，避免空矿词导致配方失效。

| 体系 | 关键物品 | 处理 |
|---|---|---|
| Thaumcraft | Thaumometer | 移除原工作台配方，改为含 GT6 钢板块的配方 |
| Botania | Lexica Botania | 移除原工作台配方，改为含 GT6 钢板块的配方 |
| Blood Magic | Blood Altar | 移除原工作台配方，改为含 GT6 钢板块的配方 |
| Witchery | Altar | 移除原工作台配方，改为含 GT6 钢板块的配方 |

钢板块代表多张 GT6 钢板，作为魔法支线的工业门槛成本较高；如后续确认当前版本存在可直接引用的 GT6 单张钢板物品栈，可将其替换为单张钢板。使用矿物词条也保留了 GT6 统一化能力。

## 本轮未改及原因

当前脚本/整合接口能处理普通工作台配方，并为 Thaumcraft 与 Botania 暴露了部分专用配方 API；但要安全修改附属模组进度，仍需逐条确认实际物品注册名、原始配方输入、研究前置和仪式/机器用途。未经核对地移除后重加会有软锁或绕过原进度的风险。

因此本轮没有擅自改动以下配方族：

- Thaumcraft 附属的研究、注魔与奥术工作台配方；
- Alfheim 的传送/精灵维度进度，Botania 的魔力注入、符文祭坛、精灵贸易等配方；
- Blood Arsenal 的血魔法专用配方；
- Magic Bees 的蜂种与蜂产品进度；
- Thaumic Energistics 的 AE2/精华整合配方；
- Deathly Hallows 与 Forgotten Relics 的独立物品/遗物来源。

这些项目需要先在当前版本中记录 NEI/专用配方实际输入与前置，再逐个加入 GT6 材料门槛；它们不应被误认为已经由本轮工作台配方改动覆盖。

## 验收提示

脚本改动尚需在游戏启动时验证 MineTweaker 解析结果，并在 NEI 中确认原配方已移除、新配方可见且钢板实际来自 GT6。修改后应完整重启游戏；不要只依赖 `/mt reload` 判断 GT6 或其他模组的配方变更。
